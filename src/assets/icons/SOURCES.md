# rainOS icon sources

The system icon layer uses open SVG assets where available. The current remote SVG Repo assets are:

| App | Source | License |
| --- | --- | --- |
| Photos | https://www.svgrepo.com/svg/436181/image-picture-gallery | CC0 |
| Messages | https://www.svgrepo.com/svg/50042/chat-messages | CC0 |
| Settings | https://www.svgrepo.com/svg/247943/settings-gear | CC0 |

These assets are used as generic interface artwork and are not Apple proprietary assets. The remaining icons currently use rainOS-owned SVG fallback artwork until an appropriate open asset is selected.

Source catalog: https://www.svgrepo.com/
